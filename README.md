# РАСПОРТ — витрина наградной продукции с двумя складами и агентом-консультантом

Демо → продакшн сайт магазина наградной продукции. Дизайн — по референсу
**art4you.ru** (премиальный B2B: журнальная сетка с линиями-разделителями,
капс-типографика Montserrat, резкие углы) в фирменных цветах логотипа
**РАСПОРТ** (красный `#E03810` + графит + белый).

## Ключевая архитектура: два блока товаров

| Блок | Источник данных | Обновление |
|------|-----------------|------------|
| **МАГАЗИН** — собственные остатки клиента | 1С → выгрузка «Остатки и доступность товаров» (xlsx) → `tools/convert_1c.py` → `data/shop-stock.json` | по мере выгрузки из 1С (без доработок 1С) |
| **УДАЛЁННЫЙ СКЛАД** — номенклатура поставщика rossimvol.ru | `tools/parse_rossimvol.py` → `data/remote-stock.json` + фото `img/remote/` | периодический запуск (cron); проданное у поставщика исчезает из витрины в следующий прогон |

Сейчас в демо: **405 медалей** из 1С-выгрузки клиента (кубков и грамот в
наличии у клиента нет) и **442 позиции** поставщика (355 кубков + 87 грамот)
с фото.

Сайт статичный: оба JSON подгружаются `fetch` на клиенте (GitHub Pages — ок);
при открытии с `file://` срабатывает компактный встроенный срез.

## Запуск

```bash
cd nagrada-mvp
python3 -m http.server 8765     # открыть http://localhost:8765/
```

## Обмен данными с 1С (виртуальный склад)

См. `tools/EXCHANGE.md` — регламент для сотрудника клиента: как выгружать
xlsx из 1С, как запускать конвертер, как настроить периодичность парсинга
поставщика. Цены в выгрузке 1С отсутствуют — розница считается прайс-моделью
конвертера (известные артикулы rossimvol ×2; при появлении колонки «Цена»
в выгрузке будет подхвачена автоматически).

## Агент-консультант «Медалькин»

`js/medalkin.js` — DOM-независимый диалоговый движок (класс `MedalkinBrain`),
переносимый в бота MAX. Умеет:
- «что есть в наличии» → товары магазина с остатками из 1С;
- «какая цена / бюджет 15000» → подборка с ценами;
- «скинь фото медалей/кубков» → карточки с фото;
- «под заказ / у поставщика» → витрина удалённого склада;
- «оформи заказ» → черновик спецификации → корзина → выбор доставки
  (самовывоз / курьер / ТК) и оплаты (наличные / карта / счёт) → данные
  покупателя → **оформленная форма заказа (спецификация) для сотрудника**
  для заведения в 1С.

## Файлы

```
index.html          — страница (шапка, герой, каталог-конструктор, процесс, футер)
css/style.css       — дизайн-система РАСПОРТ (v20)
js/data.js          — справочники + генераторы SVG-иллюстраций
js/shop.js          — витрина двух складов: JSON → сетка, поиск, сортировка, пагинация
js/medalkin.js      — мозг агента-консультанта (переносим в MAX)
js/app.js           — корзина, оформление, спецификация, чат
data/shop-stock.json    — виртуальный склад магазина (из 1С)
data/remote-stock.json  — удалённый склад поставщика (парсер)
img/remote/         — фото номенклатуры поставщика
tools/convert_1c.py     — 1С xlsx → shop-stock.json
tools/parse_rossimvol.py — парсер каталога rossimvol → remote-stock.json + фото
tools/1c-stock-sample.xlsx — реальная выгрузка клиента (пример формата)
tools/logo-source.pdf    — логотип РАСПОРТ (исходник)
```
