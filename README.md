# Наградной магазин — MVP каталога наградной продукции с ИИ-консультантом «Медалькин»

Демонстрационный прототип интернет-магазина наградной продукции для розничного
магазина, закупающего ассортимент у поставщика rossimvol.ru.
Визуальный язык — по референсу domrechi.school (тёплый крем, шоколад, тауп,
коралл; Tenor Sans + Manrope; editorial-подача, мягкие тени, тонкие линии).
Структура каталога вдохновлена витриной nb-catalog.online.

## Запуск

Всё статичное, без сборки и зависимостей:

```bash
cd nagrada-mvp
python3 -m http.server 8765
# открыть http://localhost:8765/
```

Или просто открыть `index.html` двойным кликом — работает и с файловой системы.

## Что внутри (MVP)

- **Готовые комплекты** — три дизайнерских решения под сценарий («Большой
  турнир», «Школьное торжество», «Корпоративное признание»): композиция-сцена
  из кубка, медалей и грамот, состав, цена на 10% выгоднее; скидка применяется
  в корзине автоматически при полном составе комплекта.
- **3 категории по 9 товаров**: медали, грамоты, кубки (3 в ряд × 3 строки).
- **Реальные товары и фото** — 27 позиций с rossimvol.ru (медали MMC/MD/ME/MMA,
  грамоты ГР/Д, кубки 1523–8300): настоящие названия, артикулы и фото поставщика
  в `img/`. Розничные цены = закупочные ×2 (медали/грамоты) и ×1.6 (кубки),
  округление. Фолбэк и сцены комплектов — генеративные SVG `artc`.
- **Каталог**: табы категорий со счётчиками, поиск (текст/тема/артикул),
  сортировка (цена, выгода), карточка товара, бейджи «Хит» / «−%» / «Новинка».
- **Корзина и заказ**: выдвижная панель, количество, скидка за комплект,
  оформление (имя, телефон, комментарий под гравировку), экран успеха с
  номером заказа и демо-кнопкой «Ссылка на оплату» (карта / СБП).
- **Медалькин** — ИИ-консультант, анимированный персонаж-медаль:
  - плавающая кнопка в углу + чат (полноэкранный на телефоне);
  - распознаёт категорию (медали/грамоты/кубки), тему (футбол, хоккей, шахматы,
    школа, компании, 9 Мая, 1–3 место…), бюджет («бюджет 15000 ₽») и тираж
    («50 медалей», включая бюджет на штуку);
  - знает про готовые комплекты и рассказывает о них;
  - подбирает 2–3 позиции карточками прямо в чате с кнопкой «В корзину»,
    помнит показанное («покажи ещё» не повторяется), сообщает скидки за тираж;
  - собирает заказ: сводка в чате → «Подтвердить и оформить» → форма заказа;
  - отвечает на вопросы о доставке, нанесении, оплате и MAX.
- **Мобильный-first**: сетка 2 колонки на телефоне, крупные кнопки, чат и
  корзина — полноэкранные нижние панели, safe-area для iPhone.

## Файлы

```
index.html        — разметка страницы
css/style.css     — палитра по domrechi.school: крем, шоколад, коралл, золото
js/data.js        — каталог 27 товаров + комплекты + SVG-генератор иллюстраций
js/medalkin.js    — мозг консультанта: без DOM, переносится в бота MAX как есть
js/app.js         — интерфейс: комплекты, каталог, корзина, оформление, чат
```

## Дорога к боевому продукту (обсуждается с клиентом)

1. **Каталог**: реальный импорт из прайса/сайта поставщика, фото товаров
   (механизм уже готов — поле `img`), остатки, ленты/футляры как связанные
   товары, страницы категорий.
2. **Медалькин → LLM**: замена regex-движка на языковую модель с доступом к тому
   же каталогу (интерфейс `MedalkinBrain.handle()` уже это допускает).
3. **Интеграция MAX**: `js/medalkin.js` не зависит от DOM — подключается к боту
   мессенджера; сценарий: квалификация запроса → фото товара с сайта →
   форма заказа на подтверждение → ссылка на оплату.
4. **Оплата**: реальная ссылка онлайн-оплаты (эквайринг / СБП) после подтверждения.
5. **Брендинг**: название «Наградной магазин» — рабочая метка, меняется на бренд клиента.

## Заметки по техническим находкам

- `[hidden] { display:none !important }` обязателен: у `.modal`/`.drawer__view`
  собственный `display` перебивает UA-стиль атрибута hidden, и невидимые панели
  перекрывают страницу и ловят клики.
- Открытие чата/корзины сделано на `@keyframes`-анимациях, а не `transition`:
  в тестовом WebKit transition на transform периодически «залипал» в from-состоянии.
- При замене стилей бампайте версию в `index.html` (`css/style.css?v=N`) —
  браузеры агрессивно кэшируют локальную статику.
