# Медалькин в MAX — каркас бота

Перенос сайта в мессенджер MAX: диалоговый движок **тот же класс
`MedalkinBrain`**, что работает на сайте (`js/medalkin.js`), — без изменений.
Здесь только тонкий транспортный слой: webhook MAX Bot API ↔ мозг.

## Состав

```
tools/max-bot/server.js   — webhook-сервер (Node.js, без зависимостей)
tools/max-bot/brain.js    — копия js/medalkin.js (синхронизируйте при изменениях)
tools/max-bot/goods.js    — загрузка товаров: data/*.json (1С + поставщик)
```

## Как поднять

1. **Создать бота в MAX**: https://dev.max.ru → «Мои боты» → создать,
   получить access token, включить webhook и указать URL своего сервера
   (см. актуальную документацию dev.max.ru — транспорт в server.js вынесен
   в один блок `MAX API`, сверьте имена полей с докой).
2. **Деплой**: любой Node-хостинг (VPS / Railway / Render):
   ```bash
   cd tools/max-bot
   MAX_TOKEN=ваш_токен PORT=8443 node server.js
   ```
3. **Данные**: положите рядом свежие `data/shop-stock.json` и
   `data/remote-stock.json` (или настройте общий запуск с парсером —
   бот читает их при старте и раз в час).

## Что умеет прямо из коробки

Тот же полный цикл, что на сайте: подбор под задачу/бюджет/тираж,
наличие магазина из 1С, фото (карточки-ссылки), продажа — сбор «корзины»
внутри диалога с подтверждением, пошаговое сопровождение оформления,
спецификация текстом в чат (в MAX уходит как сообщение — сотрудник может
состоять в том же чате или получать пересылку).

Отличия от сайта: корзина живёт в памяти сессии диалога (minutes TTL),
оформление — диалоговым сценарием (гравировка → доставка → оплата →
контакты), спецификация отправляется сообщением в чат поддержки магазина.
